SSH 诊断
SSH 登录进去就是 Kindle 的 root。只认你自己的公钥，没有密码登录；用完请关（开着时 Kindle 不进屏保）；重启 Kindle 后自动关闭。需要先把 SSH 诊断包（VeraDroid-SSH 文件夹）拷进 Kindle 的 documents。
允许登录的公钥

添加你自己的公钥：电脑上 ~/.ssh/id_ed25519.pub 那一整行。不要贴私钥。改了公钥要关掉 SSH 再打开才生效。

无线调试（adb）
打开后，添加过公钥的电脑可以用 adb connect 连进 Android：传文件（adb push / adb pull）、装应用（adb install）、看日志。它能完全控制 Android（包括 adb root），所以默认关、只在同一个 Wi-Fi 里能连、到时间自动关；用完请关。没有公钥的电脑连上也只会显示 unauthorized。
允许连接的电脑（adb 公钥）

电脑上先跑一次 adb devices（会自动生成密钥），再把 ~/.android/adbkey.pub（Windows：%USERPROFILE%\.android\adbkey.pub）的内容贴到这里。不要贴没有 .pub 的 adbkey，那是私钥。
